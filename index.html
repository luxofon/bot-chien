💾 Tiến trình chơi

Game tự lưu trên máy hiện tại. File save dạng chữ (.txt) dùng để chuyển tiến trình; file game HTML dùng để chơi độc lập trên máy tính.

Cách chuyển máy: máy cũ nhấn Tạo mã save → Sao chép mã → gửi mã cho chính mình. Máy mới mở game, dán mã vào ô trên rồi nhấn Dán mã & tải tiến trình. Mã save là một dãy số dài, chỉ cần sao chép và dán; không cần tải file save.

File HTML là bản game hiện tại để mở offline trên máy tính. Tiến trình sẽ tiếp tục lưu riêng trên từng thiết bị.

Reset sẽ xoá tiền, kho, nâng cấp và tiến trình hiện tại trên thiết bị này.
